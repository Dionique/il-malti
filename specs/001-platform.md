# 001 — Оболочка, хранение, алфавит

Приложение полностью статическое: HTML, CSS, JS и данные-файлы. Ни сервера,
ни сборки, ни внешних библиотек. Всё состояние — в localStorage браузера.

## Хранение

### REQ-SHELL-01 — Приложение открывается как страница
Заголовок страницы содержит название приложения. Работает без сети.

**Проверка:** `REQ-SHELL-01 title`.

### REQ-SHELL-02 — Прогресс сохраняется между сессиями и переживает обновление версии
Все результаты хранятся в localStorage под одним ключом. Загрузка состояния,
сохранённого более старой версией (без новых счётчиков), не должна ломать
приложение: недостающие разделы создаются при загрузке. Сброс прогресса
очищает состояние полностью.

**Проверка:** `REQ-SHELL-02 progress persisted`, `state from an older version
still works`, `reset clears progress`, `stats reset`.

### REQ-SHELL-03 — Переключатели запоминаются
Пользовательские переключатели (примеры, транскрипция) сохраняются и
восстанавливаются при следующем открытии.

**Проверка:** `REQ-SHELL-03 toggle persisted`, `examples toggle is persisted`.

### REQ-SHELL-04 — Ошибок в консоли нет
За всё время работы приложение не пишет ошибок в консоль и не бросает
необработанных исключений.

**Проверка:** `REQ-SHELL-04 console errors`.

## Алфавит

### REQ-ALPHA-01 — Таблица из 30 букв
Вкладка «Алфавит» показывает все 30 букв мальтийского алфавита с
произношением и примером слова.

**Проверка:** `REQ-ALPHA-01 alphabet cells`.

### REQ-ALPHA-02 — Спецсимволы под рукой
Рядом даны символы `ċ ġ ħ ż Ġ Ħ Ż għ ie q '` для копирования.

**Проверка:** `REQ-ALPHA-02 alphabet copy keys`.
