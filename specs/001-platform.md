# 001 — Оболочка, хранение, алфавит

Приложение полностью статическое: HTML, CSS, JS и данные-файлы. Ни сервера,
ни сборки, ни внешних библиотек. Всё состояние — в localStorage браузера.

## Хранение

### REQ-SHELL-01 — Приложение открывается как страница
Заголовок страницы содержит название приложения. Работает без сети.

**Проверка:** `REQ-SHELL-01 title`.

### REQ-SHELL-02 — Прогресс сохраняется между сессиями и переживает обновление версии
Все результаты хранятся в localStorage под одним ключом. Загрузка состояния,
сохранённого более старой версией (без новых счётчиков), не должна ломать
приложение: недостающие разделы создаются при загрузке. Сброс прогресса
очищает состояние полностью.

**Проверка:** `REQ-SHELL-02 progress persisted`, `state from an older version
still works`, `reset clears progress`, `stats reset`.

### REQ-SHELL-03 — Переключатели запоминаются
Пользовательские переключатели (примеры, транскрипция) сохраняются и
восстанавливаются при следующем открытии.

**Проверка:** `REQ-SHELL-03 toggle persisted`, `examples toggle is persisted`.

### REQ-SHELL-04 — Ошибок в консоли нет
За всё время работы приложение не пишет ошибок в консоль и не бросает
необработанных исключений.

**Проверка:** `REQ-SHELL-04 console errors`.

## Алфавит

### REQ-ALPHA-01 — Таблица из 30 букв
Вкладка «Алфавит» показывает все 30 букв мальтийского алфавита с
произношением и примером слова.

**Проверка:** `REQ-ALPHA-01 alphabet cells`.

### REQ-ALPHA-02 — Спецсимволы под рукой
Рядом даны символы `ċ ġ ħ ż Ġ Ħ Ż għ ie q '` для копирования.

**Проверка:** `REQ-ALPHA-02 alphabet copy keys`.

## Офлайн

### REQ-OFFLINE-01 — Ничего не грузится из сети
Все ресурсы приложения — свои: ни CDN, ни внешних шрифтов, ни сторонних
скриптов. Внешними могут быть только обычные ссылки в тексте (например, на
источник данных), по которым никто не ходит автоматически.

**Проверка:** `REQ-OFFLINE-01 нет внешних ресурсов`.

### REQ-OFFLINE-02 — Приложение устанавливается
Есть веб-манифест: имя, короткое имя, стартовый адрес, режим `standalone`,
цвет темы и фона, иконки 192 и 512. Он подключён к странице.

**Проверка:** `REQ-OFFLINE-02 манифест подключён`, `REQ-OFFLINE-02 в манифесте
есть имя, иконки и standalone`, `REQ-OFFLINE-02 иконки отдаются`.

### REQ-OFFLINE-03 — Первая загрузка кладёт всё в кэш
Service worker при установке кладёт в кэш страницу, стили, скрипт, все файлы
данных, манифест и иконки, и сразу берёт страницу под управление. Имя кэша
содержит версию сборки, поэтому новая сборка заменяет старый кэш.

**Проверка:** `REQ-OFFLINE-03 service worker зарегистрирован`, `REQ-OFFLINE-03
страница под управлением service worker`, `REQ-OFFLINE-03 в кэше все файлы
приложения`, `REQ-OFFLINE-03 в кэше стоит версия сборки`.

### REQ-OFFLINE-04 — Без сети приложение открывается и работает
После первой загрузки страница открывается и работает без сети: вкладки
переключаются, карточки показываются, прогресс сохраняется.

**Проверка:** `REQ-OFFLINE-04 без сети страница открывается`, `REQ-OFFLINE-04
без сети вкладки работают`, `REQ-OFFLINE-04 без сети данные на месте`.

### REQ-OFFLINE-05 — Видно, что приложение работает без сети
Когда связи нет, в шапке появляется пометка «офлайн»; когда связь вернулась —
пометка исчезает.

**Проверка:** `REQ-OFFLINE-05 в офлайне видна пометка`, `REQ-OFFLINE-05 в сети
пометки нет`.
